2. What Was Built

Overview

A Next.js 16 arcade hub deployed on Vercel. The home page is a retro-styled arcade lobby with game cards. Aquatic Survival is the first game — embedded in a full-screen iframe with a global leaderboard. Future games slot into the same structure.

How the Score System Works

The flow: Player finishes a run in Aquatic Survival → the game's gameOver() function fires a window.parent.postMessage({ type: 'aqua-game-over', score, kills, level }) → the Next.js game page receives it → the score submission modal auto-appears → player types their name → score saved to Neon Postgres → leaderboard updates.

The score is measured in seconds survived. Kills and level reached are stored as secondary stats. The leaderboard sorts by seconds survived (highest first).

3. Setup Still Needed — Neon Database

Status as of this session: The site is deployed on Vercel. The leaderboard API exists but the database has not been created yet. The "Top Scores" button will return an empty list until this is done.
  1. Go to Vercel → open the nano-games project → click the Storage tab
  2. Click Create Database → select Neon Postgres → follow the prompts. Vercel auto-adds DATABASE_URL to your environment variables.
  3. Run the migration — go to your Neon database in the Storage tab → open the SQL Editor → paste and run:
CREATE TABLE IF NOT EXISTS leaderboard ( id SERIAL PRIMARY KEY, game_slug VARCHAR(50) NOT NULL, player_name VARCHAR(30) NOT NULL, score INTEGER NOT NULL, kills INTEGER NOT NULL DEFAULT 0, level INTEGER NOT NULL DEFAULT 1, created_at TIMESTAMPTZ NOT NULL DEFAULT NOW() ); CREATE INDEX IF NOT EXISTS leaderboard_game_score_idx ON leaderboard (game_slug, score DESC);
  1. Redeploy the Vercel project so it picks up the new DATABASE_URL — Vercel → Deployments → Redeploy latest.

4. How to Add a Future Game

The arcade is designed so Cyrus can drop in new games over time. Here's the pattern:

  1. Add the game file — drop the HTML game file into public/games/ (e.g., public/games/space-blaster.html)
  2. Add a card on the home page — open app/page.tsx and add a new entry to the GAMES array with live: true and the new slug/colors/description
  3. Create a game page — create app/games/space-blaster/page.tsx (copy the aqua-survivor page and change the game name and iframe src)
  4. Enable leaderboard for new game — in app/api/leaderboard/route.ts, add the new slug to the VALID_GAMES set
  5. Wire up postMessage — add window.parent.postMessage({ type: 'GAME-SLUG-game-over', score, kills, level }, '*') to the game's "game over" function, then update the event listener in the new page
No database changes needed for new games — the leaderboard table stores game_slug so all games share the same table automatically.
